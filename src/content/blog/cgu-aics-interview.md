## 面試 ing

**a** : 歡迎來到長庚人工智慧學系面試，請開始自我介紹

<p class="ans"><strong>我</strong>：(說了一段很炸的自我介紹)

**a** : 說說 Transformer 原理

<p class="ans"><strong>我</strong>：(self-attention)、(如何從 QKV 得到 attention score)、(應用在哪方面)

**a** : 有沒有考 APCS ?

<p class="ans"><strong>我</strong>：(報成績)

**b** : 說說 RL 的原理

<p class="ans"><strong>我</strong>：(講成訓練方式)

**b** : (打斷) 還是說說 RL 跟 監督式學習差在哪 ?

<p class="ans"><strong>我</strong>：RL 是根據給定的 reward function 來訓練，監督式學習是透過標註好的資料從中訓練模型。

**b** : 剛剛說到 APCS ，你的程式都應用在哪方面?

<p class="ans"><strong>我</strong>：大多是在我獨自開發的專案以及人工智慧相關的應用。

**b** : 說說你的專案

<p class="ans"><strong>我</strong>：一個結合 RAG、GIS 的災害決策系統。

**b** : 為甚麼要用到 RAG 、 GIS ，他們分別負責什麼?

<p class="ans"><strong>我</strong> : 在設計回答時我沒有全丟給 LLM ，在回答之前會有一個規則層，觸發 RAG 會是當使用者問一些開放性問題時才走這個路由，GIS 主要是幫忙做一些道路規劃。

**b** : 怎麼應用在道路規劃?

<p class="ans"><strong>我</strong>：我擷取 OSM 的向量節點做成一個向量地圖，透過使用者位置的座標在 PostGIS 裡面做運算，使用最小分流演算法計算出最合適的道路規劃。

**b** : RAG 呢?

<p class="ans"><strong>我</strong>：他就是負責語意檢索，當使用者問一些開放性問題的時候才會需要他，不然很多情況下問題不會經過 LLM 。

**c** :AITC 在做什麼?

<p class="ans"><strong>我</strong>：今年錄取的計畫，目前方向是透過 ISAAC SIM 做一些機械手臂於虛擬環境的強化學習訓練，以及實體的機械手臂套用。

**c** : 看到你有看李宏毅老師的線上課程，說說你遇到不會的地方會怎麼辦?

<p class="ans"><strong>我</strong>：當遇到不太了解的數學原理我會先觀看其他線上平台的數學教學課程，搞清出那部分在做什麼再回頭看課程內容。

**c** : 看你做了蠻多事情的，你最喜歡哪部分?

<p class="ans"><strong>我</strong>：開發專案、AITC 計畫內容。

**a** : 好奇你還有報哪些科系?

<p class="ans"><strong>我</strong>：(背了一次報考名單，只挑私立的講)

**a** : 謝謝你的時間，如果正取你希望你能來我們學系。

## 心得
前面有點小炸，其實 RL 只要說 actor、observation 的那些東西就好....，因為昨天賭會問 reward 怎麼設計，滿腦子都是訓練方法，結果突然當機回答成訓練方式，有夠慘，但應該也只有那題，然後中間那個教授似乎不太懂我的專案在幹嘛，一直糾結我的 RAG 用在什麼地方，他還以為我在說的 RAG、GIS 是兩個不相干的東西，後面解釋他是一頁式的 web ，只是我有用那些東西而已，~~btw 他全程都在吃便當~~，整體感覺除了 RL 原理其他應該還行，但那邊炸掉有點小搞到心態，總之問題問的還行，感覺有稍微看過我的資料，也只挑資訊類的問，機器人、人文社會都沒被問到，就專心準備下一間吧，感覺這長庚不會錄取我。
