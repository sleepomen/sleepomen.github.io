# 模擬面試 啦啦啦
| 代號 | 身分 |
|---|---|
| a | 最左 |
| b | 左2 |
| c | 右2 |
| d | 大闕 |

這次的面試總共四位學長，在一間蠻大的房間內，最左邊是大闕，~~然後其他我就不認識了~~，然後我桌子前面放兩張蓋著的題目，anyway，開始今天的面試，然後就不照順序了，因為實在太多，問的人也不是連續的，有印象的我就開始寫。

**c** : 開始 1 分鐘的自我介紹

<p class="ans"><strong>我</strong>:(真的說了一段很炸的自我介紹，因為我沒準備一分鐘的)</p>

**b** : 看到你的專案內容，假設我今天要找一個輪椅友善的避難所麼辦，說說從下 prompt 之後的運作方式。

<p class="ans"><strong>我</strong>:問題進入後會有規則層決定你的問題走哪個路由(路徑規劃、名稱查詢之類的)，假設要找輪椅友善就走官方文件搜尋。</p>

**b** : 看到你有一些 RL 的研究，說說看你做了甚麼?

<p class="ans"><strong>我</strong>:我從基礎理論開始學習，在進入 AITC 計畫後預計會用機械手臂、ISAAC SIM/ISAAC LAB 做 RL、Mock Learning 之類的，我還在跟教授確認最後的預期成效以及成果。</p>

**b** : 我看到你有做一些 ML 的學習，如果我今天要做一個模型訓練，我要查出論文內容是否跟我要的內容相關，你的loss function 會怎麼設計?

<p class="ans"><strong>我</strong>:<small>wtf 這三小</small>目前我無法回答這些問題。</p>

**d** : 我看到你說你在高中設創人才培育計畫做了很多 Design Thinking、PBL，說說你如何在這個計畫中運用這些東西，以及做出了什麼樣的成效?

<p class="ans"><strong>我</strong>: 我們在過程中有接觸更生少年的社工，透過訪談得知更生少年相關問題，我們的定位是更生少年與社會大眾的橋樑，希望透過對外布展、桌游以及線上遊戲達到緩解大眾對於更生少年的刻板印象。</p>

**a** : 看到你有參加 DevJam TW 2026，說說看你們做了甚麼，你擔任甚麼角色?

<p class="ans"><strong>我</strong>: 我們看到了台灣行人地獄亂象，希望透過改善道路更保障行人安全，(說了系統的資料處理流程)，我負責後端開發和一些 UX 設計。</p>

**d** : 看到你的經歷有 TCCA ，為甚麼沒有內文?

<p class="ans"><strong>我</strong>: 我覺得那只是一個單純的經歷分享，就沒特別寫。</p>

**c** : 網界博覽會哪些人參加、在做甚麼?

<p class="ans"><strong>我</strong>: 每年大概固定 20 幾個國家參加，今天的主題是社區典範，我們透過採訪一位在地人物，根據他的生平事蹟整理成故事線，做成一個網站，類似網頁專題式競賽。</p>

**b** : 你專案裡面的 RAG 檢索是用內積算還是外積，差在哪裡?

<p class="ans"><strong>我</strong>: <small>wtf 這又是三小</small>目前我無法回答這些問題。</p>

**c** :你如果上了大學，會怎麼顧課業，時間怎麼分配?

<p class="ans"><strong>我</strong>: (卡了大概快30秒，沒準備這題)我認為會更加注重在課業，畢竟是該系的專業課程。</p>

**c** : 你如何自學這些東西?

<p class="ans"><strong>我</strong>: 除了人文相關領域競賽，其他都是網路自學或是問師長。</p>

<small>應該就這樣了，可能有些忘記</small>

# Feedback
1.講話語氣太平淡，有點想睡覺

2.對專案要再熟悉一點

3.如果要資訊類科系，相關經驗要先放前面

4.備審有點太長

5.要準備未來規劃相關的題目

<small>他們原本以為我的目標是資工，所以刁了我一些問題，但後來我說我想要中山人科他們就說沒關係了(沒回答的技術問題)</small>

他們說我整體回答 OK，就是語氣要再練一下，基本沒什麼問題，如果要用這個經歷報名中山人科應該是沒什麼問題。

<small>好耶</small>

問的問題蠻有水準，有些都須要想一下，比輔仁智安好多了呵呵，總之透過今天的模擬面試讓我知道還有哪些部份是我要再準備的，整體還不錯，推推。
