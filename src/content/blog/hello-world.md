Welcome to my blog! 這是網站的第一篇文章。

## 寫新文章

在 `src/content/blog/` 新增一個 `.md` 檔，開頭加上：

```yaml
---
title: 文章標題
date: 2026-10-06
category: tech   # tech 技術 / notes 心得 / life 生活
description: 一句話簡介
tags: [tag1, tag2]
---
```

## 本機預覽

```bash
npm run dev
```
